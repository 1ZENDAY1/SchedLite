# SchedLite — электронное расписание школы

## О проекте

**SchedLite** — это настольное приложение, которое показывает школьное
расписание уроков по классу, дню недели и номеру урока. Пользователь
выбирает нужные параметры с помощью кнопок и выпадающих списков, а
программа мгновенно выводит предмет, кабинет и время урока.

## Цель проекта

Упростить доступ учеников и учителей к расписанию: не нужно искать
бумажную версию или листать сайт школы — достаточно открыть программу
и выбрать нужный класс и день.

## Задачи проекта

1. Разработать удобный интерфейс на Python с использованием Tkinter.
2. Реализовать гибкий вывод расписания:
   - указан класс, день и урок → один урок;
   - указан класс и день → всё расписание на день;
   - указан только класс → всё расписание на неделю.
3. Собрать проект в один `.exe`-файл, работающий без установки Python.
4. Протестировать приложение на реальном расписании школы.

## Используемые технологии

| Технология | Зачем |
|---|---|
| **Python 3** | Язык разработки |
| **Tkinter** | Графический интерфейс (встроен в Python) |
| **SQLite 3** | Хранение расписания в одном файле `.db` |
| **PyInstaller** | Сборка проекта в один `.exe`-файл |

Все технологии бесплатные и не требуют лицензий.

## Как это работает

В приложении есть три выпадающих списка и кнопка:

- **Класс** — обязательное поле (например, «9А»).
- **День недели** — можно не выбирать.
- **Номер урока** — можно не выбирать.

Программа проверяет, какие поля заполнены, и формирует запрос к базе
данных. В зависимости от этого выводится:

- один урок с временем и кабинетом;
- всё расписание на выбранный день;
- расписание на всю неделю.

Время уроков хранится отдельно и одинаково для всех дней недели —
это упрощает базу и исключает дублирование информации.

## Ожидаемый результат

Готовое приложение `SchedLite.exe`, которое:

- запускается на любом компьютере с Windows без установки Python;
- показывает расписание по классу, дню и уроку;
